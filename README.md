

# InventoryApp

I’m excited to share my **InventoryApp**, a web-based inventory management system designed to simplify the management of products, stock, users, and inventory requests.

## Live Demo

Try the application here:

[https://inventory-app-7d5y.onrender.com/](https://inventory-app-7d5y.onrender.com/)

## Key Features

* User authentication and login
* Admin portal
* Employee portal
* Requester registration
* Product and inventory management
* Stock tracking
* Inventory requests
* Dashboard overview
* Responsive user interface
* Local data storage
* Clean and user-friendly design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* LocalStorage
* Git & GitHub
* Render

## Deployment

The application is deployed on **Render** as a static site.

**Root Directory**

```text
inventory-web
```

**Build Command**

```bash
echo "No build required"
```

**Publish Directory**

```text
.
```
